## 気をつけること

以下では、`./vendor/bin/sail` を `sail` と書いています（`alias sail='./vendor/bin/sail'` を設定すると短く打てます）。

- **`.env` の `APP_URL` は `http://localhost` のままにする**。`http://localhost:8000` にすると写真が表示されません
- **`sail down -v` は使わない**。データベースが消えます。止めるときは `sail stop`
- `sail artisan migrate:fresh --seed` は今のデータを全部消します。打つ前に `scripts/backup.sh` でバックアップを取ってください（戻し方は [`docs/backup.md`](backup.md)）
- 開発環境で送ったメール（確認のメール・パスワード再設定）は本物には届かず、Mailpit（届くはずのメールを受け止めて見せる道具）が受け止めます。http://localhost:8025 で中身を見られます

### 釣り場（実在の港と湖）

データは `database/seeders/data/real_spots.php` にあります。

- **港 131か所**：国土交通省「港湾管理者一覧表」（2025年4月1日現在）の国際戦略港湾・国際拠点港湾・重要港湾（125港）と、国土交通省「釣り文化振興モデル港」（21港。うち6港は地方港湾）
- **湖 7か所**：海のない県で、漁協などが釣りを案内している湖（岐阜県は0か所）
- **位置**：Wikidata（CC0）に細かい位置があるものだけ入れています（138か所のうち104か所）。ほかは名前だけの釣り場で、カルテに地図と天気予報が出ません。位置の間違いは、報告の「誤った釣り場情報」で知らせてもらい、管理者が直します
- **注意**：どれも注意区分は「注意あり」です。港は立入禁止・釣り禁止の場所が多いことを、湖は釣りの決まり（遊漁券など）を確かめることを、メモに書いています
- 使ったのは、商用でも使える出どころだけです（国土数値情報の港湾データの位置は、非商用のみなので使っていません）

### 釣行（開発用のダミー）

- 釣行840件（test@ が45件）は**開発用のダミー**です。実際の釣果ではありません。過去3年分です
- 管理者以外の釣り人には「ダミーの人」の印（`users.is_sample`）が付いていて、その人の釣行は画面で「ダミー」と出ます。自分で会員登録した人には付きません
- 国が釣りができると案内している「釣り文化振興モデル港」21か所に付けています（秋田港120件、ほかのモデル港は30件ずつ）。普通の港は釣り禁止の場所が多いので付けませんが、秋田県だけはプランナーで釣り場を比べられるように、船川港・能代港にも60件ずつ付けています
- 魚ごとに釣れやすい月と時間帯を決めています（例：アジ・サバは夏〜秋、メバル・アイナメは冬〜春、メバルは夕マズメと夜）。冬は坊主になりやすくしています
- 公開範囲は3段階を混ぜてあり、一部は坊主（釣果0件）。毎回同じデータになるように、乱数を固定しています
- 今いる人を管理者にするときは `sail artisan app:make-admin メールアドレス`（画面からは管理者になれません）

## データが増えたときの確かめ

記録が増えても重くならないように、集計はデータベースで行い（COUNT・GROUP BY）、全部を読み込まないようにしています。釣り場カルテの釣行の履歴は10件ずつです。

開発環境だけで使える道具で、1つの釣り場（秋田港）に釣行を3万件足して測りました。

| ページ | 直す前 | 直したあと |
| --- | --- | --- |
| 釣り場カルテ | 10,436 ms・メモリ 293.8 MB | 557 ms・メモリ 0.7 MB |
| 釣行の記録（自分） | 247 ms・3.5 MB | 133 ms・0.9 MB |
| 釣行の記録（みんな） | 545 ms・9.8 MB | 188 ms・0.9 MB |
| 釣行プランナー | 1,723 ms・109.3 MB | 206 ms・0.5 MB |
| ダッシュボード | 642 ms・16.5 MB | 241 ms・0.5 MB |

```bash
# 大量のダミーの釣行を足す（先に scripts/backup.sh でバックアップを取る）
sail artisan app:add-load-test-trips 30000

# ページの表示時間・メモリ・SQL の数を測る（それぞれ3回開いて、真ん中の値）
sail artisan app:measure-pages test@example.com /spots/1 /trips "/trips?scope=public"
```
